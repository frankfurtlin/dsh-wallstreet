# Vectra - 投资研究策略项目

## 项目定位
本项目用于投资研究策略的开发、测试和验证，**核心目标是为个人投资者（程序员背景）构建一套系统化的投资决策支持系统**。

## 投资者画像
- **职业**: 程序员
- **当前资产**: 50万存款
- **年收入**: 30万（税后）
- **风险偏好**: 激进型
- **投资期限**: 3-5年
- **时间投入**: 每天可投入
- **市场**: A股

## 核心策略
**主动量化 + 价值成长**
- 核心持仓：宽基ETF定投（50%）
- 卫星策略：行业轮动 + 个股精选（30%）
- 增强策略：网格交易 + 可转债（10%）
- 应急储备：货币基金（10%）

详见 `STRATEGY.md`

## 技术栈（已确定）
- **语言**: Python 3.10+
- **数据源**: tushare / akshare
- **量化库**: pandas, numpy, matplotlib, plotly
- **数据库**: SQLite
- **回测框架**: backtrader / vectorbt（待选）
- **可视化**: Streamlit Dashboard
- **开发环境**: Jupyter Notebook
